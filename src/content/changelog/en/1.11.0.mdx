<h2 id="winget-license-notice">WinGet license display</h2>

We confirmed that WinGet displayed MIT for HardwareVisualizer 1.11.0. The [source for that release](https://github.com/shm11C3/HardwareVisualizer/blob/v1.11.0/package.json) declares GPL-3.0-or-later, so the displayed license did not match the source declaration.

The automated release submission inherited the license metadata from an earlier WinGet manifest. We have [corrected the workflow](https://github.com/shm11C3/HardwareVisualizer/pull/2329) to use the license declared at the target release tag for future submissions. This workflow change does not update the existing 1.11.0 manifest.

If you reused or redistributed source code based on the MIT display, or that display affected your use of the software, please contact us through the [dedicated Discussion](https://github.com/shm11C3/HardwareVisualizer/discussions/2337). Share when and how you used it, to the extent you are comfortable sharing. We will review the circumstances and discuss your situation individually.

## What's New

v1.11.0 adds **Cooling Insight**, a new place to review how temperatures change alongside workload and recorded history. It also moves fresh installations to the native DuckDB archive and adds an explicit conversion flow for existing SQLite data.

For a closer look at the main feature, read the [Cooling Insight release article](https://hardviz.com/releases/cooling-insight/).

## Cooling Insight

- Added a Cooling view with synchronized history for temperature, workload, fan speed, and supported power readings.
- Added idle detection and a cooling baseline, plus daily summaries for longer-range views.
- Added load-band comparisons and a load-versus-temperature explorer.
- Added ambient-aware readings and a correlation view when compatible environmental sensor data is available.

## Hardware history

- Fresh installations use the native DuckDB archive.
- Existing SQLite data can be moved through the explicit database conversion flow.
- Added native archive queries, reconciliation, retention handling, and Storage Health reporting.

## Power and sensors

- Added Apple Silicon power draw readings and selectable power display targets.
- Added power summaries to recorded history and additional power views.
- Added Windows CPU package power and Intel package thermal status where supported.
- Added experimental motherboard temperature readings for supported ITE sensors.
- Added SwitchBot Meter BLE and Hub-family ambient readings, with explicit sensor selection.

## Setup and fixes

- Added PawnIO setup through External Component Setup on Windows. The MSI installer also offers PawnIO setup.
- Improved database conversion and recovery behavior, including after a cancelled or failed conversion.
- Includes further fixes for hardware readings, Windows installation flows, and application stability.

See the [full v1.11.0 release notes on GitHub](https://github.com/shm11C3/HardwareVisualizer/releases/tag/v1.11.0) for every change.
