# v1.12.0 公開準備

調査日: 2026-11-22。比較対象: `v1.11.3`（`1.11.x`の先端と同一）と `develop`（`2fb68b1f`）。
製品側のパスは HardwareVisualizer リポジトリのルートが起点。実機での動作確認は行っておらず、すべてコード・文書・Issue・CIの読み取りによる。

## 公開前に解決・判断すること

### 公開を止める条件

1. **公開日**: ADR 0028 と[RFC #2014](https://github.com/shm11C3/HardwareVisualizer/issues/2014)は、プロダクトアナリティクスのクライアントを含む版を2026-12-03より前に公開しないと定めている。developにはクライアントが入っている（`src-tauri/src/analytics/`）。それより前に出すなら、クライアントを外す必要がある。
2. **分析サービスのリポジトリ**: `hardviz-product-analytics`は非公開。設計文書は「Public before any client release」、告知文はリンクを初回リリース前に追記するとしている。
3. **センサーサービスの検証**: ADR 0029 のリリース条件のうち、最終MSIの導入、ログオン時、標準ユーザー、スリープ復帰、更新・ロールバック・削除、署名済み成果物の検証が未完了（[#2509](https://github.com/shm11C3/HardwareVisualizer/pull/2509)）。

### 利用者への影響が大きいもの

4. **差し戻しによる履歴の削除**: DuckDBのスキーマが1から2へ上がり、v1.11.xでは開けない（Resetで削除される）。[#2755](https://github.com/shm11C3/HardwareVisualizer/pull/2755)で1.12.0は保持期間の既定値を保存しなくなったが、修正のないv1.11.xへ戻すと設定保存時に30日が保存され、1.12.0へ戻った起動時に古い履歴が削除される。v1.11.3と`2fb68b1f`の設定コードを交互に実行して30日が残ることと、事前に保存すれば防げることを再現した（実際の削除とUI操作は未検証）。根本的に防ぐには1.11.xへのバックポートが必要。#2755の本文には、起動時の権限判定が一時的に失敗すると、その回の削除が30日で走りうるという未修正の経路も記載されている。
5. **MSI以外でのPawnIO取得の停止**: 本体からの直接取得がなくなった。exe版・ポータブル版・Program Files外のMSI版は、管理者実行でも取得できない。アプリ内更新でもexe版はexe版のまま。
6. **未知のPawnIOモジュール**: `.amx`、手動で入れた新しいモジュールは読み込まれず、セットアップでも置き換わらない。

### developのCI

7. **性能テスト**: Windowsで2026-11-16の`1c24d215`以降6回連続失敗（[#2494](https://github.com/shm11C3/HardwareVisualizer/issues/2494)）。修正の[#2754](https://github.com/shm11C3/HardwareVisualizer/pull/2754)はマージ済みで、修正後の定期実行の成功は未確認。
8. **OSVスキャン**: 2026-11-09から`startup_failure`で、定期の脆弱性検査が動いていない。その前から`failure`が続いていた。

### 範囲の判断

9. **分析の同意画面**: developにはない。公開までに入るなら、更新履歴・記事・安全性・プライバシー・比較・トップの記述を変更する。

## v1.11.3時点ですでに誤っていたサイトの記述

[#452](https://github.com/shm11C3/hardviz-webpage/pull/452)で先行して修正し、2026-11-22にmasterへマージ済み。このブランチにも取り込んだ。

- 設定名「詳細設定」は正しくは「高度な設定」（対応状況、v1.11.0の紹介記事）。
- PawnIOのセットアップは不足分のコピーだけでなく、古いモジュールの置き換えも行う（導入ガイド）。
- AMD Family 1Ahのパッケージ温度は実験的に対応済み（導入ガイド）。
- `llms.txt`のCooling Insightのリンク先がリリース記事で、導入ガイド・安全性・比較の各ページがなかった。

## アプリ側の文書で古いもの

- READMEの日英: LinuxのNVIDIAにDRMが必要とある（#2647で不要）。DIMM温度にProtectli VP2430がない。
- READMEの通信先: Google Fontsがない。developでも`src/index.css`が読み込んでいる。
- READMEは分析を「今後のリリース」としている。公開時にADR 0028と告知文のStatusも更新する。

## サイト側に残るもの

- 画面画像は1.11系のまま。撮り直す画面: パフォーマンス（ネットワークパネル）、インサイト（1年表示）、システム仕様（ヘッダーのボタン）。記事用に設定のセンサーサービス欄。
- v1.10.1の更新履歴がない。
- 比較ページの他社製品の列は再調査していない（確認日は2026-11-11・12のまま）。

## 公開手順

ブログ一覧とフッターの変更は[#454](https://github.com/shm11C3/hardviz-webpage/pull/454)で2026-11-22にmasterへマージ済み。このブランチでは1.12.0の記事を一覧に登録している。

このブランチは公開済みとして書いてある。**v1.12.0のリリース前にmasterへマージしない**（pushで本番に公開される）。プレビューデプロイも公開URLになる。

1. `develop`の先端が`2fb68b1f`から進んでいれば、`git log 2fb68b1f..v1.12.0`を原稿に反映する。
2. 仮の日付`2026-12-03`を公開日に置き換える: `rg '2026-12-03' src`。プライバシーポリシーの`December 3, 2026`と`2026年12月3日`、Aboutの`2026.12`も確認する。
3. `src/data/releases.ts`の`windows-sensor-service`に`publishedAt`を設定する。紹介記事とブログ一覧の日付に反映される（未設定の間は日付なしで一覧に載る）。
4. 更新履歴のfrontmatterにある仮日付のコメントを削除する。
5. GitHub Release、MSI、Wingetの公開後にマージし、ダウンロードページがv1.12.0を指すことを確認する。
